# Supply Chain Analytics & Decision Intelligence Platform

## Overview
This project shows an end-to-end analytics workflow designed to transform operational data into actionable business insights.

The project covers:
- Data preparation
- Exploratory analysis
- Predictive forecasting
- Optimisation modelling
- Statistical evaluation
- Interactive dashboard development

## Tools Used

Python | Pandas | NumPy | SQL | SQLite | Streamlit | Plotly | Machine Learning

## Business Problems Addressed

- How can demand be forecasted more accurately?
- How can inventory levels be optimised?
- How can operational risks be identified?
- How can analytics improve business decisions?
